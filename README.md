## 👨‍💻 Sobre mim

Administrador de Banco de Dados com atuação em **Oracle Database, da versão 9i às versões atuais**, e **Microsoft SQL Server**. Trabalho com administração e sustentação de ambientes, backup e recuperação, monitoramento, análise de desempenho, troubleshooting, automação e documentação técnica.

Meu foco é construir ambientes previsíveis, seguros e recuperáveis, com mudanças rastreáveis, validação técnica e planos claros de rollback.
